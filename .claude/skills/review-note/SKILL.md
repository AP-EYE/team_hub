# 피드백 정리 (review/)

## 파일

- 교수·멘토 피드백: `review/YYYY-MM-DD-<피드백 준 사람>.md` (여럿이면 `-`로 잇는다)
- 팀 내부 회의: `discussion/YYYY-MM-DD 주제.md`
- 녹취 원문이 길면 `review/YYYY-MM-DD-녹취.md`로 따로 두고 링크한다.

## 형식

```markdown
# YYYY-MM-DD <누구> 피드백

- 일시·장소:
- 참석:
- 출처: 녹취(STT) / 메모 / 채팅

## 결정
- 팀이 하기로 한 것. 한 줄씩.

## 피드백
### <피드백 준 사람>
- 지적·조언 요지. 녹취 타임스탬프가 있으면 (mm:ss)를 붙인다.

## 질의응답
- Q. / A.

## 할 일
- [ ] 무엇을 / 누가 / 언제까지 (모르면 TBD)

## 원문
녹취 원문 또는 링크
```

## 규칙

- 원문은 고치지 않는다. STT 오인식은 요약 부분에서만 바로잡는다. 예: 볼라→BOLA, 205K→200 OK, 깃톱→GitHub.
- 고친 용어가 확실하지 않으면 `원문 표기(추정: X)`로 적는다.
- 말하지 않은 결정을 만들지 않는다. "검토하기로 함"과 "하기로 함"을 구분한다.
- 잡담·사담은 원문에서 빼도 되고, 뺐다고 적는다.
