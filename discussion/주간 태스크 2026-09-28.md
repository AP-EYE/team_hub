# 주간 태스크 (09-28 ~ 10-04)

> **보류 (2026-09-29).** 멘토링에서 "구현보다 핵심 가설과 근거 논문이 먼저"라는 지시를 받아, 이번 주는 가설 조사(09-30 마감)로 바뀌었다. 아래 구현 계획은 가설이 확정된 뒤 다시 짠다. [2026-09-29 멘토링 피드백](../review/2026-09-29%20%EB%A9%98%ED%86%A0%EB%A7%81%20%ED%94%BC%EB%93%9C%EB%B0%B1.md) 참고.

## 이번 주 목표

**10/4까지 crAPI 엔드포인트 3개가 수집, 판정, 점수를 거쳐 결과 JSON 한 개로 나온다.**
사전, 가중치, 판정 규칙은 임시값이어도 된다. 끝까지 한 번 이어지는 것이 목표다.

대상 엔드포인트 3개:

| # | 엔드포인트 | 정답 | 고른 이유 |
|---|---|---|---|
| 1 | `GET /identity/api/v2/vehicle/{vehicleId}/location` | BOLA 위반 (챌린지 1) | 이미 재현했다. 기준점 |
| 2 | 챌린지 2 엔드포인트 (`crAPI/docs/challenges.md`에서 양유상이 확정) | BOLA 위반 | 두 번째 정답 |
| 3 | `GET /community/api/v2/community/posts/{postId}` | 공개 설계 (위반 아님) | 공개 API 오탐 여부 확인. 교수 피드백 1번 |

## 월~화: 전원 공동 (먼저 끝내야 각자 작업이 된다)

**팀 회의 1회, 1시간.** 안건 두 개.

1. **단계 사이 데이터 형식 고정.** crAPI 차량 위치 응답 한 개를 놓고 아래 세 JSON의 실제 예시를 만든다. 주관: 심재훈.
   - 엔드포인트 인벤토리 (곽민경 → 심재훈)
   - 탐지 결과 (심재훈 → 임성빈)
   - 영향도 점수 (임성빈 → 리포트)
   - 필드 경로 표기 규칙도 같이 정한다. 예: `data.owner.email`, 배열은 `items[].email`
2. **10/29 중간 발표 목표 수치 두 개 확정.** 인가 탐지 수, 오탐 수. 초안은 [2026-09-23 계획 발표 피드백 대응 현황](../review/2026-09-23%20%EA%B3%84%ED%9A%8D%20%EB%B0%9C%ED%91%9C%20%ED%94%BC%EB%93%9C%EB%B0%B1%20%EB%8C%80%EC%9D%91%20%ED%98%84%ED%99%A9.md) 5번 표에 있다.

완료 기준: 합의한 JSON 예시 세 개가 저장소 `schemas/` 폴더에 올라가 있다.

## 수~일: 각자

### 심재훈 - 판정 (3단계 Detector)

| 작업 | 완료 기준 | 예상 |
|---|---|---|
| GitHub 저장소 개설, 폴더 구조, `schemas/` | 팀원 4명이 push 가능 | 1시간 |
| 판정표 수정: 동일 뷰 행을 개인정보 포함 여부로 분리 | [ARCHITECTURE](../arch/2026-09-29%20%EA%B2%8C%EC%9D%B4%ED%8A%B8%EC%9B%A8%EC%9D%B4%20%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98.md) 6.4 반영 | 30분 |
| 필드 델타 판정 함수 (규칙만, 모델 없이) | 인벤토리 JSON을 넣으면 위반, 검토 필요, 정상 중 하나가 나온다. 테스트 입력 3개로 확인 | 4시간 |
| 세션 교차 재생 최소판 (GET만) | 계정 B 토큰으로 엔드포인트 1번 재생 성공 | 3시간 |

### 곽민경 - 수집 (1단계 Collector)과 게이트웨이

| 작업 | 완료 기준 | 예상 |
|---|---|---|
| mitmproxy 리버스 프록시로 crAPI 앞에 게이트웨이 띄우기 | 게이트웨이를 거쳐 crAPI 로그인 성공 | 2시간 |
| 요청·응답 기록 애드온 | 계정 2개로 엔드포인트 3개 호출한 기록이 파일 또는 PostgreSQL에 남는다 | 4시간 |
| 경로 변수 일반화 + 인벤토리 JSON 출력 | `/vehicle/실제ID/location`이 `/vehicle/{id}/location`으로 묶여 합의 형식으로 나온다 | 4시간 |
| 로그 적재 전 토큰 마스킹 | 저장된 로그에서 Authorization 헤더 평문 검색 결과 0건. 교수 피드백 4번 | 1시간 |

### 임성빈 - 영향도 (4단계 Scorer)

| 작업 | 완료 기준 | 예상 |
|---|---|---|
| CIM 공통 스키마 항목 v0 (15개 내외) | `user.email`, `user.phone`, `user.name`, `vehicle.location` 등. crAPI 3개 엔드포인트의 필드가 전부 매핑된다 | 3시간 |
| 한국 개인정보 유형 사전 v0 | 주민등록번호, 휴대전화, 계좌, 이메일, 위치 등 필드명 사전 + 값 정규식 | 3시간 |
| 법 분류 3등급과 임시 가중치 | 민감정보, 고유식별정보, 일반, 비식별에 임시값. 근거 조문 표기 | 1시간 |
| 점수 함수 | 탐지 결과 JSON을 넣으면 엔드포인트별 점수가 나온다. 1번과 3번 점수가 다르게 나온다 | 3시간 |

### 양유상 - 벤치와 평가

| 작업 | 완료 기준 | 예상 |
|---|---|---|
| 대상 3개의 정답표 | 엔드포인트, 정답 판정, 노출 필드, 근거 챌린지 번호가 적힌 파일 | 2시간 |
| 테스트 계정 2개와 리소스 준비 스크립트 | 스크립트 한 번 실행으로 계정, 차량, 게시글이 만들어진다 | 3시간 |
| 채점 스크립트 v0 | 결과 JSON과 정답표를 비교해 맞은 수, 오탐 수를 출력한다 | 3시간 |
| VAmPI 구동과 공개 엔드포인트 확인 | VAmPI가 뜨고, 누구에게나 같은 응답을 주는 엔드포인트 목록이 나온다 | 2시간 |
| 로컬 모델 비교 준비 (jeff, SemIf) | 둘 중 하나라도 로컬에서 응답이 나온다. 정확도 비교는 다음 주 | 2시간 |

## 일요일: 첫 연결

- 각자 만든 부품을 수동으로 이어 붙인다. 곽민경 인벤토리 → 심재훈 판정 → 임성빈 점수 → 양유상 채점 순이다.
- 완료 기준: 엔드포인트 3개의 결과 JSON 한 개가 나오고, 채점 스크립트가 맞은 수와 오탐 수를 출력한다.
- 안 이어지면 어디서 형식이 어긋났는지만 기록한다. 고치는 건 다음 주로 넘긴다.
