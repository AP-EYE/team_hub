## 기준 (2026-10-02 조재현 멘토 피드백)

- 합성 API를 직접 만들어 평가하지 않는다. 연구 결과를 아는 사람이 만든 데이터는 정확도를 편향시킨다("그들만의 리그").
- 선행 논문이나 퍼저가 쓴 데이터셋을 써도 된다. 그 논문의 수치보다 개선됐음을 보이면 된다.
- 리뷰어가 납득할 만한 기준점을 고른다.
