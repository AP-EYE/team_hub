## 1. 연구 방향 (가장 중요, 9/29 멘토링)

| 요구 | 상태 |
|---|---|
| 구성도는 구현 대상이 아니라 주제 찾기 도구다. 구현만으로는 연구 가치가 없다 | 반영 중 |
| 핵심 가설을 한 문장으로 세운다. "기존 A는 X를 못 한다(근거 논문). 우리는 몇 %까지 푼다" | 초안 있음 (선택지 2) |
| 가설은 우리 주장이 아니라 논문 근거에서 나와야 한다 | 2607.16754 한계에서 출발 |
| 이미 풀린 문제면 연구할 필요가 없다. 최신 연구까지 확인한다 | 1차 조사 완료 |
| 논문 하나를 골라 그 한계와 트레이드오프에서 출발하는 방법도 된다 | 선택지 2가 이 방식 |
| 정확도와 속도 중 무엇을 볼지는 기존 연구를 따른다 (본 논문들은 정확도 중심) | 미정 |
| ChatGPT에 "비슷한 연구 있어?"만 묻지 말고 PDF를 직접 읽는다 | 3_연구/papers/ 폴더에 원문 저장 |
| 인가 진단 하나만 제대로 해도 학술 가치가 충분하다 | 인가 판정을 본체로 둠 |
| Jev(또는 대체재)를 직접 써 보고 거기서 문제를 찾아라 (최한림) | 양유상 SemIf 실험, 문제점 확인 |
| 데모는 필수가 아니다. 문제 확인 수단일 뿐이다 | 해당 없음 |
| 금요일에 논문을 근거로 교수를 설득하라 | 10/2(금) 16시 |
