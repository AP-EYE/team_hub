# 데모 수용 기준과 독립 검증 계획

이 문서는 실행 전 정한 판정 기준이다. 실제 통과 여부는 `evidence/integration-tests.json`과 모델 평가 산출물에 기록한다. 시연용 합성 데이터의 결과를 실제 서비스 탐지율이나 법률상 유출 확정으로 일반화하지 않는다.

## 독립 평가 실행 결과

2026-09-22 연결 풀 도입 후 최종 통합 평가에서 HTTP·로그·결합 분석 검사 60개가 통과했다. 이 집계에는 별도 의미론·DB 장애 단위 테스트 17개의 통과 여부를 확인하는 검사 1개가 포함된다. 이전 실행 ID와 이벤트 해시가 PostgreSQL에 보존됐는지도 직접 조회해 확인했다. 실제 실행 시각, 전체 사례, 파일 해시는 `evidence/integration-tests.json`을 기준으로 한다. 새 코드로 서버를 다시 시작했다면 같은 평가를 재실행해야 한다.

| 합성 시나리오 16개 | 취약 모드 | 수정 모드 |
|---|---:|---:|
| 확인된 정책 위반 | 5 | 0 |
| 정책상 허용 | 8 | 9 |
| 정책상 거부가 실제 차단됨 | 2 | 6 |
| 정책 미등록으로 검토 필요 | 1 | 1 |
| 비인가 응답에서 관측한 정보주체 수(테넌트 포함 중복 제거) | 3 | 0 |

공개 프로필·명시적 공유 접근은 정상으로 판정했다. Bob의 alpha/U100 프로필과 상담 응답은 연결했고, beta/U100은 다른 사람으로 유지했다. 인증 헤더·쿠키·쿼리의 합성 비밀 표식은 저장 상태와 보고서에서 발견되지 않았다.

평가 과정에서 ‘거부 정책 + 200 응답’만으로 빈 본문·오류 본문도 취약점으로 확정하는 결함을 찾아 수정했다. 회귀 테스트는 빈/오류 200과 요청 대상·실제 반환 대상 불일치를 `needs_review`로 남기는지 확인한다. 검증 대상은 고정한 합성 계약이며 임의의 외부 API를 잘 판별한다는 성능 주장은 아니다.

연결 풀 도입 후 첫 회귀에서는 55개 검사가 통과한 뒤 로컬 HTTP 연결에 `WinError 10053`이 발생했다. 원인은 확인되지 않았으며 서버의 health 재확인 후 재시작이나 코드 변경 없이 한 차례 재실행하여 60/60 통과했다. 실패 원본은 `evidence/integration-pool-first-failure.json`에 보존했다. 이 결과를 장기 무장애 운영의 증거로 해석하지 않는다.

DB 장애 테스트는 실행 중 PostgreSQL을 중단하지 않고 in-process 예외를 주입했다. 연결 오류와 풀 대기 시간 초과 시 HTTP 503, 저장 미확인 안내, 내부 예외정보 비노출을 확인했다. 상류 API가 데이터를 반환했더라도 로그 저장에 실패하면 성공 데이터나 증거 이벤트 ID를 반환하지 않는지도 검증했다.

## 실행 경계

- 대상: 이 저장소가 띄운 localhost 합성 API와 게이트웨이만 사용한다.
- 능동 진단: 승인된 GET 사례만 재전송한다. 주문 생성·결제·삭제 같은 상태 변경 요청은 재전송하지 않는다.
- 인가 판정: 사전에 고정한 정책과 관측된 응답을 비교한다. 모델의 추측을 정책으로 승격하지 않는다.
- 모델 평가: 규칙과 로컬 분류 모델의 결과를 구분하며, 모델 미실행·실패는 성공으로 표시하지 않는다.
- 법적 분류: 법정 범주의 후보와 기술적 노출 관측을 제공한다. 신고 의무·위법성·전체 피해 규모를 자동 확정하지 않는다.

## 인가 정확도 측정

정답이 있는 정책 사례에 한해 TP/FP/FN/TN을 집계한다. `needs_review`를 정답으로 간주해 정확도 분모에서 조용히 제거하지 않는다. 알려진 정책의 커버리지, 검토 대기 건수, 인가 탐지 정밀도·재현율을 함께 보고한다. 공개·공유 정상 사례는 반드시 음성 사례에 포함한다.

프라이버시 분류는 필드별 정답을 사용한다. 필드 의미 정규화와 값의 민감정보 여부를 분리한다. 학습·예시·규칙 작성에 사용한 데이터와 최종 평가 데이터를 구분해야 하며, 작은 합성 평가의 점수는 실제 운영 성능의 증명이 아니다.

## 이 데모에서 합격해도 남는 것

프로덕션 배포 적합성, 모든 API 자동 탐색, 실제 JWT 검증, 대규모 성능, 장기 로그 무결성, 운영 권한 관리, 실제 피해 인원 확정, 법률적 결합 특정성의 보편적 판정은 별도 과제다. 관측되지 않은 우회 경로·과거 로그·암호화된 본문을 복원했다고 주장하지 않는다.
