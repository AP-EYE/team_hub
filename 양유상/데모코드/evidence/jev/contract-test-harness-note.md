# 계약 테스트 초기 실행의 수정 사항

첫 실행은 27개 중 13개 통과, 14개 실패였다. HTTP 계약 테스트가 ASGI 내부 주소로 `http://test`를 사용해 앱의 기존 TrustedHost 미들웨어에서 모두 `400 Invalid host header`를 받았다. 모델 호출이나 개인정보 분류 실패가 아니며, 테스트 fixture의 Host를 허용된 `http://127.0.0.1:8810`으로 수정했다. 서버 동작·인가·모델 코드나 허용 호스트 목록은 변경하지 않았다.

수정 후 실행 증거는 `contract-tests.xml`에 저장한다. 이 테스트들은 로컬 모델 HTTP 클라이언트를 mock으로 교체하고 ASGI lifespan을 실행하지 않아 실제 모델 추론·DB 초기화·로그 저장을 수행하지 않는다. mock 점수는 전송 계약 확인용이며 한국어 분류 정확도 측정에 포함하지 않는다.
