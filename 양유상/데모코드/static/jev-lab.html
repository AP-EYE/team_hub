점수 분포·오분류·UNKNOWN 검토

선택지 점수는 정해진 선택지들 안에서 정규화한 값입니다. 90%라고 해서 실제 정답률이 90%라는 뜻은 아닙니다.

허용 토큰 질량은 모델의 전체 다음 토큰 분포에서 허용 선택지에 배정된 확률의 합입니다. 선택지 내부 점수와 함께 확인합니다.

기대 분류는 이번 데모용으로 지정한 실험 기준입니다. 입력이나 모드를 바꾸면 기존 정답과 자동 비교하지 않습니다.

프롬프트 공격이 포함된 값도 데이터로 취급해야 합니다. 높은 점수의 오분류를 따로 확인하는 이유입니다.

REPRODUCIBLE LOCAL RUN

실행 환경과 평가 근거

SemIf는 이전 OpenJev 프로젝트의 오픈소스 구현입니다. 공식 TypeSafe Jev의 제품 성능이나 실행 결과로 해석하지 않습니다. 이 데모는 개인정보 분류 후보를 만들며 인가 정책이나 법적 결론을 자동 변경하지 않습니다.
