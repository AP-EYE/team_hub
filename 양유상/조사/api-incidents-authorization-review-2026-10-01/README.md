## 우선 추천

팀의 중심 연구에는 **최소 정책 근거와 선택적 인가 판정(H1)**, 개인정보 노출 중심 대안에는 **정책 변경 이후 응답 필드 진단(H3)**을 추천한다. 기존 BOLA 주제와 분리되는 추가 연구에는 **권한 회수의 시간 계약(H2)**이 적합하다. 추천 이유와 실패 조건은 통합 보고서에 있으며 성능 우월성·학문적 신규성은 아직 미검증이다.

가설 번호는 문서별 로컬 번호다. 이 색인의 H1–H8은 통합 보고서를 기준으로 한다. 실무 도구·기업 공지·동료심사 논문·프리프린트를 같은 근거 등급으로 취급하지 않는다.
