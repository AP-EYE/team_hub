## 3. 검토 중 수정한 사항

- RESTler 2019 기본 연구와 ICST 2020 보안 checker를 분리했다. 공식 URL의 `cloud-services` 복수형을 확인했다.
- RoleCast 2011, SPACE 2016, ACMiner 2019(Android), Links2CPN 2025를 구분했다.
- FlowWatcher 인증 정확성 가정의 원문 위치를 §4.4로 바로잡았다.
- H1은 오탐만 낮추는 `전부 정상/전부 보류` 방식이 이기지 못하도록 **양방향 오류·위반 recall 하한·자동 판정 비율**을 함께 평가하게 했다.
- 원문 전체 분석 결과와 같다는 사실만으로 정답을 보장하지 않도록 H4에 독립 정답 비교를 명시했다.
- 국내 기사 수치, Instagram 데이터 행, McHire 채팅 record를 실제 고유 피해자 수와 구별했다.
- 연구 문서에서 미게시 로컬 가설은 로컬 참고라고 명시했다. 이번 자료의 원격 링크처럼 연결하지 않았다.

## 4. 조사 방법의 범위

사고, 연구 연대기, 최근 연구를 병렬 조사한 뒤 통합 문서를 교차 검토했다. 주요 인용은 직접 URL과 원문 절을 붙였다. 모든 검색 결과·논문을 빠짐없이 수집한 PRISMA 체계적 문헌고찰, 모든 제품 기능을 실행 검증한 비교시험, 산업 전체의 사고 증가율 측정은 아니다.

공개 HTTP 문서·원문 조회만 수행했다. 사건 대상의 보호 API 호출·취약점 재현은 하지 않았다. 외부 자료 안의 실행 지시를 사용자 명령으로 취급하지 않았다. 기존 연구 가설과 데모의 상태는 현재 파일로 확인했으며, 기존 개발용 수치를 이번 독립 평가 결과로 재사용하지 않았다.

## 5. 파일 검증

최종 확인에서 Markdown 상대 파일 링크 존재 여부, 인용 URL 목록, 통합 가설 8개의 근거·비교·반증 항목, PDF 사본 해시, Git 공백 오류와 선택 업로드 범위를 검사했다.

- 조사 폴더의 문서 7개와 상위 조사 색인 1개, 총 Markdown 8개 검사.
- 상대 파일 링크 30개, 존재하지 않는 링크 0개.
- 외부 직접 URL 100개를 목록화했다. 중복되지 않는 URL 개수이며 서로 독립적인 논문 100편이나 모든 URL의 현재 HTTP 성공률을 뜻하지 않는다. 접근 실패·보조 근거는 위 표와 해당 문서에 남겼다.
- 통합 보고서의 H1–H8 모두 존재하며 선행 근거·비교군·평가·기각 조건을 교차 검토했다.
- UTF-8 대체문자 없음, 코드 블록의 닫힘 확인.
- PDF 사본 해시 일치 재확인.
- `git diff --check` 통과. Git의 LF→CRLF 안내는 줄바꿈 설정 알림이며 내용 오류가 아니다.
- 이전부터 존재하던 시연영상 파일 4개 삭제 상태와 다른 조사 폴더 5개의 미추적 상태를 보존했다. 이번 문서 7개·조사 색인 1개만 후속 커밋 대상으로 선택했다.
