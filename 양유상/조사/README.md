## 기존 게이트웨이 조사

`api-gateway-research-2026-09-21/`은 프로젝트 주제를 정하기 위해 작성한 조사 묶음입니다. 네 문서의 역할은 다음과 같습니다.

1. `01-architecture.md` — 게이트웨이·수집기·정책·로컬 모델·저장 구조
2. `02-detection-and-privacy.md` — BOLA/BFLA/BOPLA 구분, 개인정보 분류·결합·영향도 경계
3. `03-implementation-and-evaluation.md` — 단계별 구현, 합성 데이터, 독립 평가와 실패 보존
4. `04-sources-and-review.md` — 선행 도구·공식 문서·검토 질문과 남은 불확실성

원문 첨부는 [`source-materials/`](source-materials/)에 있습니다. 이 자료는 설계의 출발점이며, 실제 동작 여부는 `projects/api-privacy-gateway-demo/evidence/`의 실행 증거로 별도 확인해야 합니다.
