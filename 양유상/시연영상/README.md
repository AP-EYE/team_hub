# 킥오프 데모 촬영 자료

이 폴더에는 데모 촬영 시 지킬 설명 범위와 근거 문서를 둡니다. **완성 영상은 아직 없습니다.** 촬영 후 MP4와 최종 자막을 이 폴더에 추가하면 됩니다.

녹화 전에는 [합성 데모 실행 안내](../데모코드/README.md)에서 서버와 로컬 분류 작업자 상태를 확인합니다.

## 촬영 시 지킬 설명 범위

- 화면은 로컬 데모의 합성 계정·요청·개인정보 사례만 사용합니다.
- 로그 조사 수치는 선택된 합성 실행의 관측값입니다. 실제 침해 규모나 피해자 전체 수로 표현하지 않습니다.
- 로그 증거가 없는 응답 범위는 `0`이 아니라 `알 수 없음`으로 설명합니다.
- CIM은 공통 필드 정규화 개념을 참고한 것이며, 공식 CIM 호환·인증을 주장하지 않습니다.
- SemIf는 공식 TypeSafe Jev와 구분합니다. 96건 결과와 선택지 점수는 검토 후보이며 법률 판정이나 보정된 확률이 아닙니다.
