# 킥오프 데모 영상

[**한국어 내레이션과 화면 자막이 포함된 MP4 시연 영상**](rendered/video/AP-EYE-kickoff-demo.mp4)을 공유합니다. 길이는 약 3분 38초이며, 1600×900 해상도입니다. 별도 자막 파일은 [`captions.vtt`](captions.vtt)입니다.

## 영상 순서

| 시간 | 내용 |
| --- | --- |
| 00:00 | 주제 소개와 시연 범위 |
| 00:22 | 게이트웨이 대시보드와 인가 판정 근거 |
| 01:06 | 요청·응답 로그와 추적 정보 |
| 01:27 | alias 필드 정규화와 식별자·테넌트 경계 기반 결합 |
| 01:46 | 저장된 로그로 호출 13건, API 8종, 관측 정보주체 3개 조사 |
| 02:08 | 응답 증거가 없는 메타데이터 전용 로그의 한계 |

| 02:51 | 합성 개발 평가셋 96건의 비교 결과 |
| 03:15 | 오분류 사례와 사람 검토 필요성 |

## 결과 해석

영상은 로컬 데모의 합성 계정·합성 요청·합성 개인정보 사례만 보여줍니다. 사후 조사 수치는 선택된 저장 실행에서 관측된 범위이지 실제 침해 피해 규모가 아닙니다. 응답 본문이나 필드 로그가 없으면 대상자·항목 수는 0이 아니라 `알 수 없음`으로 남깁니다.

한국어 분류 결과는 직접 작성한 합성 개발용 사례 96건을 기준으로 SemIf 82/96(85.4%), 같은 Qwen3 4B 계열 GGUF의 JSON 방식 81/96(84.4%), 규칙 기준선 73/96(76.0%)이었습니다. SemIf 오분류 14건 중 12건은 선택지 상대 점수가 90% 이상이었습니다. 이 점수는 보정된 확률이 아닙니다. 결과는 독립 블라인드 평가나 실제 서비스 정확도를 뜻하지 않으므로, 분류와 우선순위는 검토 후보로만 제시하고 법률 판단이나 자동 승인에 사용하지 않습니다. 여기서 SemIf는 공식 TypeSafe Jev와 별개의 오픈소스 구현을 가리킵니다.

## 재생성

Windows의 한국어 음성과 로컬 데모 서버가 필요합니다. 먼저 데모 서버를 `http://127.0.0.1:8810`에서 실행한 뒤 이 폴더에서 다음 명령을 실행합니다.

```powershell
.\generate_narration.ps1
py -3 .\build_audio.py
$env:DEMO_PLAYWRIGHT_MODULE = '<Playwright 모듈 경로>'  # Node가 playwright를 바로 찾지 못할 때
$env:DEMO_BROWSER_EXECUTABLE = '<Chrome 또는 Edge 실행 파일>' # 자동 탐지가 안 될 때
node .\record-demo.cjs
py -3 .\build_audio.py  # 녹화된 장면 전환 시각에 맞춰 음성과 VTT 동기화
uv run --with imageio-ffmpeg python .\encode_video.py
```

녹화는 저장된 합성 데모와 평가 결과를 읽습니다. 모델 추론을 다시 실행하거나 실제 API에 요청을 보내지 않습니다. 화면 흐름과 내레이션 원문은 [`scenes.json`](scenes.json)에 있으며, 재사용 스크립트는 이 폴더에 있습니다.
